一、先建立整体地图：私募基金行业全景

用最少的术语，搞懂私募基金是什么、分几类、被谁管、怎么运转。

✅ 本章速览：私募是什么 ✅ 证券 vs 股权两类私募的区别 ✅ 为什么"合规"是刚需 ✅ 募投管退生命周期

1.1 私募基金是什么（一句话版）

私募基金 = 面向合格投资者（高净值个人/机构）非公开募集、由私募基金管理人运作的基金。

和公募基金的区别，用一个对比就记住：

维度公募基金私募基金
向谁募集向大众公开宣传不公开宣传，只面向合格投资者
投资门槛10 元起单人最低 100 万元 起步
信息披露严格、定期披露几乎不公开披露
谁在管基金公司（公募牌照）私募基金管理人（中基协登记）

1.2 两类私募，投研逻辑完全不同（这是关键！）

很多人一上来把"私募"当成一个东西，其实它分两类，投研逻辑截然不同：

维度私募证券投资基金私募股权/创业投资基金
投什么二级市场：股票、债券、期货、期权、基金一级市场：未上市企业股权
看什么上市公司财报、行业景气、股价项目商业计划、团队、赛道
决策节奏快（日/周/月级调仓）慢（投决会，数月调研）
投研重心研究→选股→组合→风控→交易项目储备→尽调→投决→投后→退出
行业规模整个私募行业管理规模约 23.5 万亿元（2026 年 4 月末，中基协）；证券类约 7.9 万亿元
⚠️

做产品前先确认客户类型。如果你做的是"投研"产品，先确认目标客户是证券类私募（二级市场，投研系统核心诉求）还是股权类私募（更多是项目尽调与投后管理，叫"募投管退"系统）。本手册重点讲证券类私募投研——这是"投研心法"最密集的地方。

1.3 行业监管框架（理解"合规"为什么是刚需）

  • 监管机构：中国证监会；自律组织：中国证券投资基金业协会（中基协）
  • 核心制度："管理人登记 + 基金备案"二元体系
    • 私募基金管理人要在中基协登记（类似"牌照"）
    • 每只基金产品要备案
  • 关键法规：
    • 《私募投资基金监督管理暂行办法》（2014，基础性法规）
    • 《私募投资基金监督管理条例》（2023.9.1，国务院条例，监管升级）
    • 《私募投资基金登记备案办法》（2023.5.1）
    • 《证券期货投资者适当性管理办法》（投资者适当性）
  • 合格投资者标准：金融资产不低于 300 万元，或近三年年均收入不低于 50 万元；单只私募证券基金投资门槛 100 万元（股权 300 万）
  • 合规要求：投资者适当性管理（风险测评→匹配）、双录（录音录像留痕）、信息披露（季度报告等）
💡

产品含义：合规留痕、适当性管理、信息披露报告是私募管理人的刚性需求，系统能帮他们"不出事"。但这是"及格线"功能，不是差异化竞争力。差异化竞争力在"帮他们赚钱"的投研功能上。

1.5 钱是怎么流动的？管理人靠什么赚钱？

一句话：投资者把钱交给管理人，管理人拿去买资产，赚了钱分给投资者，自己抽成。

💰 钱怎么流动
  1. 1
    投资者（LP）认购基金，把钱打进来
  2. 2
    管理人（GP）用这笔钱建投资组合
  3. 3
    买股票 / 债券 / 期货…这就是投研团队的活儿
  4. 4
    净值涨跌产生收益或亏损
  5. 5
    回馈投资者赎回时按份额拿回本金和收益

↺ 循环往复：赎回后资金又可重新认购，周而复始

💸 管理人怎么赚钱（记住 "2/20"）
管理费
1%–2% / 年
按规模收，旱涝保收
业绩报酬
20%
赚了钱才抽成（Carry）

举例：管 10 亿，管理费 2% = 2000 万/年；一年赚 1 亿，再抽 20% = 2000 万。行情差时只赚管理费，行情好时两头都赚。

※ 这正是私募"重业绩"的原因：业绩好，规模才涨得动，管理费和业绩报酬都水涨船高——所以帮管理人"做出好业绩"的投研工具，是直击核心利益的产品。

1.6 私募基金的常见策略类型（你未来的用户画像）

同样是"私募投研"，不同策略的团队工作方式天差地别。认识它们，才知道你的产品要服务谁：

📈股票多头主观 · Long Only
最主流。靠"研究公司 → 买好股票 → 长期持有"赚钱，主观判断主导。代表：高毅、景林、淡水泉。对"研究沉淀+决策留痕"系统需求最强烈的群体。
🤖量化指增 / 市场中性Quant
靠模型和算法选股、交易，追求跑赢指数或对冲后稳赚超额。代表：幻方、九坤、明汯。主要用米筐/聚宽这类量化平台。
🛢CTA（管理期货）Commodity Trading Advisor
主要交易期货，抓商品/股指的趋势，跟股票关系不大，风控看波动率。
🌐宏观对冲Macro
判断宏观经济和大类资产（股/债/汇/商品）的涨跌来下注，以宏观数据研究为主。
💵债券策略Fixed Income
投债券，赚票息和价差，波动低。研究重心是信用风险（会不会违约）。
🧩多策略 / FOFMulti-strategy / Fund of Funds
组合多种策略，或投资一篮子基金（FOF）。核心是"配置"而非"选股"。
🔑

给产品经理的提示：不同策略的用户，投研需求完全不同——主观股票多头要"研究沉淀 + 决策留痕"，量化团队要"回测 + 因子 + 数据"。做产品前先想清楚：你的 MVP 服务哪一类？本手册后续章节重点服务主观股票多头（需求最空白、最值得做）。

小白帮记：7 千多家证券私募里，85% 都是 5 亿以下的小作坊（很多就是"老板+几个研究员+Excel"）；真正够得上"腰部"的只有 600 多家——每一家都养得起你，关键是拿下其中 15%。

TAM/SAM 估算：把"蓝海"变数字

  • 单家年付费（客单价）：按席位定价，10 人团队 × 3-6 万/人/年 ≈ 30-60 万/年；按机构打包价 30-80 万/年
  • SAM（腰部核心市场）：650 家 × 50 万 ≈ 3 亿/年
  • SAM（含小型私募轻量版）：6,800 家 × 2-5 万 ≈ 1.4-3.4 亿/年（做引流层）
  • 合计可服务市场 ≈ 5-7 亿/年（单点产品的天花板；扩展到组合/风控/数据，空间更大）
⚠️

诚实的话：这个盘子不大（不到国内 SaaS 市场的 0.1%）。结论不是"别做了"，而是打法必须匹配：别做重平台（覆盖不了成本），做"单点极致 + 高价高粘性"——拿下 100 家腰部客户（15% 渗透率）就是一年 5 千万的生意，够养一家 30-50 人的精品公司；同时靠 AI 能力把客单价往上打。

📌 本章小结
  1. 私募 = 面向合格投资者、非公开募集、100 万起投的基金，分证券类（二级市场）和股权类（一级市场）两大类。
  2. 本手册聚焦证券类私募投研——投研心法最密集、产品机会最大的地方。
  3. 合规（登记备案、适当性、双录）是刚需，但只是"及格线"，差异化在"帮他们赚钱"。
  4. 记住 "2/20"：管理人靠 1–2% 管理费 + 20% 业绩报酬赚钱，所以业绩是命根子。
  5. 策略分很多种：股票多头、量化、CTA、宏观、债券、多策略——先锁定主观股票多头。
  6. 最新数据：全行业 23.46 万亿（2026.4），腰部 10-100 亿私募约 620-700 家，可服务市场约 5-7 亿/年——蓝海真实存在，但必须单点切入。

2.4 一个被反复强调的行业事实

系统永远是跟着机构的"办法、流程、制度"走的，不要做"用系统重构业务流程"的白日梦。—— 资管行业数字化转型共识

含义：做产品前要先理解客户已有的流程（晨会、投决会、风控委员会），系统去贴合、放大、提效这些流程，而不是强行定义新流程。

📌 本章小结
  1. 客户分三层：头部（百亿+，自研）、腰部（10–100 亿，投研 SaaS 核心客户）、小型（付费弱）。
  2. 核心岗位：基金经理（拍板）、研究员（研究推票）、交易员、风控、IR。
  3. 一句话痛点：研究不沉淀、决策不留痕、组合看不清、风险守不住、复盘没依据。
  4. 铁律：系统要贴合机构已有的流程，别妄想用系统重构流程。

3.4 为什么"数据"是投研系统的地基

  • 研究员现状：Wind/Choice 客户端 + Excel + Python 手工搬运数据
  • 系统要做的事：把数据接入、清洗、标准化，让研究员"开箱即用"
  • 难点：① 精准覆盖研究员需求（行业数据差异极大）② 改变使用习惯很难
  • 数据质量要求：Point-in-Time（用当时能拿到的数据回测，避免未来函数）、及时性、准确性

3.5 机构的三大标准流程 SOP（系统"贴合"什么，就看这里）

小白疑问：手册强调"系统贴合流程"，但晨会、投决会、风控委员会到底怎么开的？下面给出典型 SOP（依据：券商/公募公开的投决会议事规则、恒生 O32 系统业务流程）。注意不同机构细节差异大，SOP 的价值是给你一个问客户问题的框架。

① 晨会（每日）—— 信息与观点对齐会

晨会就像学校的早读+班会：每个人报告昨晚作业（隔夜市场）、谁有新发现（推票）、班主任（基金经理）布置今天的重点。开完会，大家脑子里要有一个统一的"今天看什么"。

  1. 07:30 交易员/研究员汇总隔夜外盘、大宗商品、政策/公告
  2. 08:00 晨会（30-45 分钟）：宏观/策略研究员讲隔夜市场与今日关注；行业研究员报持仓异动、重点公告、新推票（每人 1-3 分钟）；基金经理给方向、定调（"今天重点看消费"）
  3. 08:45 会后：研究助理整理晨会纪要 → 分发到各人待办
💡

产品含义：晨会纪要 + 待办分发 + 推票登记是天然的"研究协作"场景。晨会推票没被记录，是多数私募认知流失的第一个漏斗——嘴上说了、群里聊了，三天后就找不到了。

② 投决会（投资决策委员会）—— 拍板的会议

投决会就是公司的董事会。买股票像"立项做项目"——研究员是项目经理，写方案（研报）、过评审（投决会）、投票通过才能动钱。

  1. 立项：研究员/基金经理提交立项申请（标的、逻辑、预期赔率）
  2. 尽调/研究：补充深度报告（财务模型、估值、风险点）
  3. 上会：投决会（通常 3-7 人：高管 + 基金经理 + 风控 + 外部专家顾问）
  4. 表决：按议事规则投票——简单多数（过半数）/ 绝对多数（2/3）/ 全票。小额常规调仓经理权限内自行决定（备案即可）；大额、新标的、越界必须上会
  5. 记录：会议纪要 + 表决结果归档（合规留痕，涉及追责）

小白帮记表决规则：钱越多、越没买过的东西，要越多的人同意。简单多数 = 超过一半人举手；绝对多数 = 2/3 以上；全票 = 所有人——"大额新仓"往往要求最高。

💡

产品含义：投决会流程是"决策留痕"天然载体——会议前自动打包（研报+模型+历史观点）、会中记票、会后归档形成决策档案。用"留痕"服务合规刚需（出问题能自证），而不是服务追责。

③ 风控委员会 / 风控流程（守住底线）

  • 事前：交易指令过风控规则（单票/行业/杠杆上限、禁投池、止损线）→ 触发即拦截或转人工审批（O32 等系统实时执行）
  • 事中：盯盘监控（净值预警线、回撤阈值、集中度）→ 分级预警推送
  • 事后：日/周风控报告 + 异常交易复盘

④ 交易执行链路（O32 系统的标准业务流）——这是"系统贴合流程"的业界范本：

  1. 投资决策 → 基金经理下发指令 → 合规/风控检查 → 交易员拆分执行 → 报盘成交
  2. 日终清算对账（交易所/中登）→ 估值（FA/中债估值）→ 报告

小白帮记 O32：它是机构的"交易大脑"——所有买卖指令、风控检查、成交清算都在这里跑。你的 SaaS 如果有一天要接真实交易数据，就是跟它打交道（详见 6.6 节）。

📌 本章小结
  1. 研究员的一天 = 晨会 → 看盘 → 读研报 → 调研 → 写报告 → 复盘。
  2. 投研本质循环 7 步：获取信息 → 研究 → 观点 → 建仓 → 跟踪 → 卖出 → 复盘，复盘成果回流形成飞轮。
  3. 机构投研框架就六个字：读、研、写、验、荐、评——这就是投研系统的功能骨架。
  4. 数据是地基但最难做；先从"流程"切入比从"数据"切入更实际。
  5. 三大流程 SOP：晨会（信息对齐）、投决会（立项→尽调→表决→归档，多数/2/3/全票）、风控（事前拦截→事中预警→事后报告）——系统先贴合这三张流程图。

四、投研心法总览：哪些"心法"能被系统化

投资大师的方法论听起来玄，但大量可以被翻译成系统功能。点击每张卡片展开看「心法内容」和「能做成什么功能」。

✅ 11 大心法逐个拆解 ✅ 每个心法 → 具体功能 ✅ 第 6 章把功能组装成产品
只投自己真正看得懂的生意，不懂不投。能力圈的大小不重要，清楚边界最重要。
可系统化的点
  • 行业覆盖标注：研究员/基金经理覆盖哪些行业，避免越界
  • 能力圈评分卡：每只标的要求回答"是否理解生意模式/商业模式/盈利来源"，不理解的强制标记
  • 能力圈标签：给标的上标签（品牌消费品/平台/周期/科技…），与持仓者覆盖能力匹配
好公司要有可持续的竞争优势——品牌、网络效应、转换成本、成本优势、无形资产、规模经济。
可系统化的点
  • 护城河评估模板：标准化的评估维度（无形价值/转换成本/网络效应/成本优势/有效规模），逐项打分 + 证据留痕
  • 护城河变化跟踪：定期复核，标记"护城河收窄/加宽"，触发提醒
"牛市在悲观中诞生，在怀疑中成长，在乐观中成熟，在兴奋中死亡。""街头溅血时买入。"
可系统化的点
  • 情绪/关注度指标：研报数量热度、搜索热度、媒体情绪、北向资金流，量化"市场恐慌程度"
  • 跌幅扫描器：自动列出"跌幅榜"，配合基本面筛选（跌得多但基本面不烂 = 潜在逆向机会）
  • 极端点位标记：在个股/指数历史估值分位上标注历史顶底区间（冯柳的"基本面坐标体系"）
假定自己在信息、理解、精力、情绪上都处于市场最差水平，只依靠时间、赔率与常识。
核心内容
  • 前提：自己是"弱者"，靠时间、赔率、常识取胜
  • 风格：不择时、不对冲、不用杠杆、不做空、高仓位、赔率优先
  • 选股标准："可预期、可展望、可想象"
    • 可预期 = 能搞明白 1 年内的业绩和估值
    • 可展望 = 大致感受 3 年的发展路径
    • 可想象 = 对 10 年后的未来有期盼
  • 下跌分类：杀估值（最好，跌下来原因就解除）、杀业绩（次之，按经营节奏投）、杀逻辑（最危险，不碰）
  • 关注度 × 购买度矩阵：高关注低购买（估值易抬升，好）；高关注高购买（估值有压力，回避）
  • 卖出：梦想落空时出逃 vs 达到预设后收手
可系统化的点
  • "10-3原则"检查清单：强制回答"10年后企业还在且更好？3年内盈利提升+估值提升？"
  • 下跌性质分类器：自动/半自动判断下跌属于杀估值/杀业绩/杀逻辑（结合盈利预测下修幅度 vs 估值变化）
  • 三段式研究模板：把"可预期/可展望/可想象"变成填空
  • 关注度-购买度四象限图：研报数量 × 成交量/筹码结构自动绘制
  • 负面情景压力测试：列出最悲观逻辑，问"最悲观成立也不怕吗"
买价格显著低于内在价值的资产，用"安全边际"保护自己；"第一条规则是不要亏钱，第二条是记住第一条"。
可系统化的点
  • 估值工具库：DCF、PE/PB/PS 分位数、EV/EBITDA、股息率等，一键计算并对比历史区间
  • 安全边际提示：当前价 vs 内在价值估算的折扣率，低于阈值高亮
  • 一致预期数据（朝阳永续核心产品）：全市场分析师盈利预测汇总，与自主预测对比找"预期差"
下注 = 概率 × 赔率。胜率不高但赔率极高时值得小仓位参与；胜率赔率双高时重仓。
可系统化的点
  • 交易计划模板：强制填写"看多逻辑、看空逻辑、目标价、止损位、仓位建议、预期赔率（上行空间/下行空间）"
  • 赔率计算器：自动算上行空间/下行空间比值
  • 仓位建议模型：凯利公式参考仓位 vs 集中度限制取 min
年化收益率的小差距（3–4 个百分点）经过时间复利放大后天壤之别；避免大幅回撤是复利的关键（亏 50% 需要涨 100% 才回本）。
可系统化的点
  • 复利视图：组合净值曲线的长期复利展示，回撤区间高亮（水下曲线）
  • 回撤管理：最大回撤监控、回撤形成天数/修复天数统计、回撤超阈值预警
  • "不要打扰复利"：把换手率、交易成本可视化——高换手如何侵蚀复利
从"知道规则"到"无条件执行"是投资里最难的一公里：回测时冷静，实盘时手抖；明知该止损却不执行。
可系统化的点（产品蓝图的黄金区域）
  • 规则引擎 / 计划-执行对照：事先设定止损线/止盈线/仓位上限，系统自动监控，触发后强提醒（甚至对接交易系统自动执行）
  • 纪律打分：统计"计划 vs 实际执行"的偏差，生成纪律分
  • 情绪标注：下单时让用户标注情绪状态（冷静/FOMO/恐慌/贪婪），复盘时关联情绪与盈亏
把每一次亏损变成系统升级的燃料；复盘要看对问题（"真问题" vs "表层问题"）。
可系统化的点（产品机会巨大，详见第六章）
  • 交易迭代日志：决策还原 → 模式识别 → 归因分析 → 系统升级（一个具体的"补丁"）
  • 复盘顺序：先看客观信号 → 再比对主观操作 → 最后看盈亏结果（避免结果导向偏见）
  • 认知错题本：把共性错误归类成"认知盲区对照表"（如：追涨杀跌=无系统；不止损=侥幸心理）
  • 研究结论可证伪：每个研究观点必须写下"什么情况出现=我的观点错了"（证伪条件），系统定期提醒复核
先想怎么不亏，再想怎么赚。真正好的风险控制来自"充分深入的思考"，但机械指标是底线。
可系统化的点
  • 风控指标库：预警线/止损线（产品层面）、回撤控制、仓位上限、个股/行业集中度、杠杆率、流动性监控
  • 实时监控面板：组合风险仪表盘（Beta、波动率、VaR、最大回撤、行业暴露）
  • 压力测试：极端情景（如市场跌 20%）下的组合表现
  • 合规红线：禁止投资标的池、关联交易、单一持仓上限
研究员推票没被采纳怎么算？市场环境差导致模拟盘亏损怎么算？考核规则怎么设计才站得住？
现实问题：模拟盘考核容易被骂
  • 绝对收益率失真：市场涨跌是 Beta、个股选择才是 Alpha——牛市人人都是股神，熊市都亏钱
  • 未采纳的推票：研究员推了但经理没买，赚亏都算不到研究员头上
  • 短期化：季度排名逼出短炒和频繁推荐，深度研究被挤掉
  • 推票和报告质量脱钩：只盯收益率，没人看报告是否严谨、风险提示是否充分
业界怎么改："双维考核 + 递延"框架
  • 基准层：模拟盘相对基准的超额收益（对标指数/行业基准，而非绝对收益排名）——剔除市场 Beta，公平性核心
  • 扣减层：合规错误（每次 2-8 分）、逻辑漏洞（每次 1-2 分）——把"研究质量"拉回考核，约束短炒
  • 调节层：路演评价系数（0.8-1.2）、推荐继续率、投诉率——拉长评价周期，看推荐是否经得起时间检验
  • 递延：季度奖金的 20-30% 递延 6-12 个月发放——让研究员对推荐的后验表现担责
🔑

用考试打比方：这套框架 = 一场讲究公平的期末考——基准层不看绝对分，看"比班级平均（指数）高多少"；扣减层卷面不整洁、审题不严谨直接扣分；调节层老师同学觉得你讲得好不好、你押的题半年后还押不押得中；递延奖学金先押 20-30%，期末考完半年"没翻车"才发。

给产品经理的落地建议
  • 默认用超额收益：系统自动对标基准（沪深300/中证500/行业指数），一键切换
  • 推票状态机：推票 → 登记"建议采纳/未采纳/暂缓" → 未采纳的推票也独立跟踪（单独标记）——解决"经理没买算谁的"
  • 报告质量分：从填写完整度、证伪条件是否写明、风险提示是否充分自动打分，计入考核
  • 把"打脸"变成"学习"：错题本和复盘默认仅个人可见，老板要的"纪律分"是团队维度汇总，不点名晒单——留痕才能推得动
  • 规则透明可配置：考核公式对研究员可见、可解释（"我这季度为啥扣分"），避免黑箱
🔑

心法→功能的翻译口诀：大师的每句话，都能问三遍——"它能变成表单字段吗？能变成自动计算吗？能变成提醒规则吗？"三问都"否"的，才暂时不做。

5.3 关键洞察（为什么说这是蓝海）

  • 重平台（Wind AMS / 恒生）：功能全但重、贵、上线周期长（虽然 Wind 宣传 3 天），适合大机构

空白地带："研究协作 + 决策留痕 + 认知沉淀 + 复盘进化" —— 几乎没有成熟产品系统性解决，而这是所有私募投研团队（尤其腰部以下）最痛的。恒生韩海潮的"读研写验荐评"、监管的"平台型团队制"导向都在给这个方向背书。

为什么大厂不做（空白地带成因分析）？

  • 商业模式错配：Wind/恒生的收入靠"终端订阅 + 系统实施 + 数据售卖"，卖的是工具——像出租车，上车付钱、到站下车；"复盘进化/决策留痕"是流程运营型产品——像驾校，需要学员天天来练、教练天天陪，才能教会习惯。大厂的销售体系卖不动这种需要长期陪跑的累活。
  • 用户规模不经济：腰部私募总共 600-700 家，按 50 万/年也才 3 亿市场，进不了大厂的产品线优先级（恒生 WarrenQ 2.0 做的是 AI 读/写/算——Chat、脱水研报、会议助手；朝阳 Go-Goal 做数据挖掘 + AI 智能体；通联做量化/AI 配置——都绕开了需要用户深度参与的"复盘沉淀"）。
  • 大机构自己建，中小机构没人管：华夏、高毅等头部自建投研体系；腰部私募既没有自建能力，也不在恒生/Wind 的射程内——这就是空白地带。
  • 结论：不是"没人试过"，而是"大厂做了不划算、小厂还没做到"。窗口期取决于你多快把"用户填报习惯"建立起来——先发者的壁垒是用户数据资产，不是功能。

留痕为什么会被抵制，怎么设计才推得动？（人性问题）

一句话类比：让员工"写工作日志给老板看"，他只会写"今天开会、处理邮件"；但如果日记是给自己看的、还能帮他发现"我总在周五冲动下单"——他反而愿意写。留痕产品要做的，是后一种日记。

  • 威胁感知："决策留痕、不可篡改"对研究员 = 每次被打脸都被永久记录、发年终奖时算总账——这是威胁不是福利，推广必被抵制。
  • 对策一：默认私有，汇总公开。个人复盘/错题本默认仅本人可见（像写日记）；老板看到的"纪律分"是团队维度聚合，不点名晒单。留痕服务于"自己成长"，追责服务于"组织合规"，两者数据分层。
  • 对策二：价值前置。先给研究员"赢"的感觉：系统自动帮他发现共性错误、生成月度认知报告（"这个月你的亏损 70% 来自追涨"）——他主动愿意填。
  • 对策三：借监管东风。2025 年监管罚单里"未按规定留痕"是高频处罚事由——留痕是合规刚需，老板有动力推；把"合规留痕"作为卖点卖给老板，把"认知成长"作为福利卖给研究员。
  • 对策四：不可篡改但可解释。时间戳+不可篡改用于防"马后炮"；但给用户"补充说明/事后批注"的权限（原记录不变，允许追加解释），减少对抗感。

① 券商对账单/估值表导入银行寄流水单：客户从券商 APP/托管行导出交易流水、持仓、净值，系统自动解析Excel/CSV 模板标准化MVP 必选：零集成成本、当天能用
② PB 系统 / 中后台系统对接找银行要标准对账单：券商帮客户管账户的系统（PB=主经纪商业务），要它导标准格式文件客户已有恒生/券商系统时做文件级对接早期客户陪跑
③ O32/O45/UFX 接口直连跟"交易大脑"装电梯：O32 是机构的"交易大脑"，UFX 是它给外部系统留的"插座"实时拉指令/成交/持仓；需券商/恒生授权，门槛高大客户私有化阶段
  • 研究员手工录入的激励问题：纯手动录入必死（用户没动力）。对策：① 行情/估值数据系统自动补全，用户只需录"交易动作"（买/卖/仓位），把录入量降到最低；② 录入与考核挂钩（录入越完整，考核分越准，老板越认可）；③ 用券商对账单批量导入兜底，Excel 作为低保真过渡。
  • 隐私与合规：交易数据敏感，需客户授权+私有化部署选项；SaaS 模式下建议数据脱敏/分权（研究员只见自己的模拟盘，老板见汇总）。

6.7 AI 的机会点（所有竞品都在试）

🤖
AI 能力
提效而非替代，赋能而非荐股
  • AI 研报摘要/公告解读：把长公告压缩成"影响点 + 投资含义"
  • AI 预期差扫描：从一致预期数据中自动发现超预期/低于预期标的
  • AI 复盘助手：对决策日志做归因与模式识别（参考"回想"App、交易迭代日志的 AI 化）
  • AI 问答：自然语言查询数据（"帮我筛出 PE 分位<20% 且 ROE>15% 的消费股"）
  • AI 情绪标注：从文本推断市场情绪/关注度（支持逆向投资心法）
⚠️

注意红线：不能做"荐股"（合规），定位是"过程支持"，不是"决策替代"。

AI/自动化的合规边界到底划在哪？（把"红线"说清楚）

监管依据：《证券、期货投资咨询管理暂行办法》（1997）、《证券投资顾问业务暂行规定》（2010/2011 施行）、《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》（2012 发布、2020 修订）。

什么是"荐股软件"（碰了就要牌照）？软件只要具备以下任一功能，就属于"荐股软件"，向投资者销售并获利 = 从事证券投资咨询业务，必须取得证券投资咨询业务资格：

  1. 提供涉及具体证券品种的投资分析意见，或预测具体品种价格走势
  2. 提供具体证券品种选择建议（选股名单）
  3. 提供具体证券品种买卖时机建议
  4. 提供其他证券投资分析、预测或建议

用大白话翻译："告诉你买什么、什么时候买、会涨会跌" = 荐股（要牌照）；"给你数据和工具，让你自己想" = 安全区。

六大严禁行为（无论持牌与否都不能做）：

  1. 代理投资人买卖证券/期货（替客户下单）
  2. 承诺投资收益（"稳赚不赔"）
  3. 与客户约定分享收益或分担损失（赚了一起分、亏了一起扛）
  4. 为自己买卖股票（自己偷偷炒股）
  5. 利用咨询服务合谋操纵市场或内幕交易（组团割韭菜）
  6. 虚假/误导性宣传（吹牛夸大历史业绩）
⚠️

2025 年监管在严打（不是纸上规定）：2025 年前 4 个月，21 家投顾机构收 33 张罚单、8 家被暂停新增客户（1-6 个月）；处罚事由集中在误导性宣传、承诺收益、无证人员提供投资建议、适当性不规范、未按规定留痕等。

给你的产品画一条可执行的红线：

✅ 能做（过程支持）❌ 不能做（决策替代/荐股）
预期差数据展示（"市场预期 1.2 元，实际 1.3 元"）输出"买入 XX 股""目标价 XX"的结论
事实/数据筛选工具（PE 分位、跌幅榜）给出具体品种的买卖时机建议
决策日志、复盘、纪律分（过程记录）承诺收益或暗示稳赚
研究员自主观点留痕（人写的，非机器推）面向个人投资者的荐股类推送/课程
面向机构内部使用的工具面向 C 端/大众投资者的投资建议分发

判断口诀：你的产品是"帮机构里的人更好地思考"（safe），还是"替人做投资决定并对外分发"（risky）？前者永远安全，后者需要牌照且监管正严打。

6.8 商业化与落地思考

  • 目标客户：腰部私募（10–100 亿）最有付费意愿；小私募可做轻量版/免费引流
  • 形态：SaaS（云）为主，数据敏感的大客户可私有化
  • 数据采购成本是大头——通过"系统+数据"打包或与数据商合作分账
  • 切入点建议：从"复盘进化"或"研究沉淀"这种空白功能切入（差异化），再向组合/风控扩展（Wind/恒生覆盖但贵）
📌 本章小结
  1. 投研一体化 SaaS 分三层：工作台 → 五大模块（研究/组合/风控/复盘进化/运营）→ 数据层。
  2. 差异化核心是复盘进化模块：决策日志、纪律打分、归因、错题本、证伪提醒。
  3. 切入点：先做"复盘进化"或"研究沉淀"单点，跑通再扩组合/风控。

7.2 做产品的实操建议

  1. 先访谈 3–5 家腰部私募：问他们晨会怎么开、研究员考核怎么定、亏损怎么复盘、知识怎么沉淀。比读十本书有用。
  2. 观察"Excel 里有什么"：用户现在用 Excel 管理什么，哪里就缺产品。Excel 结构 = 产品原型。
  3. 别一上来做重平台：从单点（如复盘进化）切，做出让研究员"用了就回不去"的功能。
  4. 心法必须翻译成"填空"：不要在产品里写"请进行护城河分析"，要写"请为以下 5 个维度打分并附证据"。
  5. 留痕是刚需也是护城河：时间戳、不可篡改、版本记录——既是合规要求，也让用户离不开（数据资产积累）。
  6. 模拟盘考核是抓手：帮老板"考核研究员"是付费决策人最关心的，也是最容易量化的价值。

7.4 失败模式清单：这个产品"容易怎么死"（小白必读）

手册前文都在讲"该做什么"，这里补上"容易怎么死"——把这六条当成排雷清单：开工前先问自己"这几颗雷我踩得到吗？"每个失败模式都来自行业真实案例（SaaS 通用失败 + 金融行业特有）。

💀 失败模式 1：用户不录入 → 数据流干涸
死法：产品靠研究员手动填复盘、填观点，但研究员觉得"填表=加班"，两周后没人填，产品变成空壳。
对策：① 录入量最小化（行情/估值自动算，只录交易动作）；② 价值前置（先让用户"拿走"数据：自动生成月报/认知报告）；③ 与考核绑定；④ 用券商对账单/Excel 批量导入兜底。
💀 失败模式 2：留痕被抵制 → 老板买了，研究员不用
死法："不可篡改"被解读为"秋后算账"，研究员消极应付、只填废话。
对策：默认私有+汇总公开（见 6.5 节）；给"事后批注"权限；把留痕同时包装成合规刚需（监管要求的留痕义务）与个人成长工具。
💀 失败模式 3：数据打不通 → 复盘失真
死法：真实交易数据拿不到（券商接口要授权、恒生 O32 对接周期长），靠手动录导致数据不全，复盘结果不可信，产品价值归零。
对策：MVP 阶段只用对账单导入；把"数据打通"作为交付流程的一部分（客户陪跑，先文件级对接，再谈接口）；私有化大客户再上 O32/UFX 直连。
💀 失败模式 4：市场太小撑不起重投入
死法：按"平台化"打法招 50 人做全功能，650 家腰部客户覆盖不了成本，烧完融资倒闭。
人话版：小区门口开了一个 5000 平米的巨型超市，但小区只有 600 户人——再好的货架也撑不起租金。
对策：单点切入（复盘进化/模拟盘考核），30-50 人精品公司打法；客单价靠"考核+合规"绑定提上去（30-80 万/年）；先用小团队验证 3-5 家付费客户再扩张。
💀 失败模式 5：合规越界 → 一票否决出局
死法：产品被认定为"荐股"（见 6.7 红线清单），或被用于承诺收益，监管处罚+客户流失。
对策：产品文案/功能对照红线清单自检；面向机构内部（B 端）而非 C 端分发；不做收益承诺。
💀 失败模式 6：客户付不起钱 → 腰部也嫌贵
死法：数据成本（Wind 数据源）吃掉毛利，定价不得不高；腰部私募 2024 年普遍降本增效，50 万/年嫌贵。
人话版：客户预算就 20 万，你报价 50 万，理由还是"我进数据的成本就 30 万"——客户只会说"那我直接买 Wind 不就行了？"
对策：用平价数据源（Choice/iFind/公开数据）起步，把数据成本压到收入的 10% 以内；按席位/模块定价留下降级空间；对小型私募做轻量版引流。
📌 本章小结
  1. 先补知识：财务三张表、估值、A 股规则、投资流派、绩效指标。
  2. 再动手：访谈腰部私募、看他们 Excel 里有什么、从单点切入。
  3. 避开红线：不做荐股/收益承诺，不碰合规运营红海，只做"心法系统化"地带。
  4. 六大死法记牢：不录入、被抵制、数据断、盘子小、越红线、付不起——每一条都有对应对策，把它们写进你的产品风险清单。
