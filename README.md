# 私募基金投研领域 · 产品经理入门手册

> 一份面向**完全零基础**产品经理的交互式学习手册，把私募基金投研领域「讲透、讲明白」。
> 读完你就能听懂投研人说话，知道该做什么样的产品来真正帮助他们。

## 这是什么

本手册围绕四个问题展开：

1. **私募持仓管理人是谁？** —— 行业全景、玩家分层、组织架构
2. **他们每天在干什么？** —— 买方投研的一天与完整工作流
3. **他们痛在哪里？** —— 三类核心用户的真实需求
4. **投研心法怎么变成产品功能？** —— 10 大心法逐一翻译成系统功能

内容基于公开资料系统研究整理，重点落在「**投资心法 → 产品功能**」的落地方法上，帮助产品经理做出真正有价值的投研工具。
