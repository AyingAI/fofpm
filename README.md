# 基金领域 · 产品经理入门手册（私募 + 公募）

> 面向**完全零基础**产品经理（也适合想认真了解基金的普通人）的交互式学习手册系列，把基金领域「讲透、讲明白」。
> 读完你就能听懂基金人说话，知道该做什么样的产品来真正帮助他们。

## 这个仓库有什么

| 手册 | 服务对象 | 解决什么问题 |
|---|---|---|
| [**私募基金投研领域**](./私募基金投研领域产品经理入门手册.html) | 私募投研产品经理（B 端） | 私募持仓管理人是谁、投研一天怎么过、投研心法如何变成系统功能 |
| [**公募基金投资领域**](./公募基金投资领域产品经理入门手册.html) | 公募产品经理 + 普通基民（C 端） | 普通人每天在基金 App 上干什么、为什么"基金赚钱基民不赚钱"、市面上为什么充满情绪信息、好产品该做什么 |

两本手册基于公开资料系统研究整理，所有关键数字均标注时点与来源，重点落在「**投资心法 → 产品功能**」的落地方法上。

## 快速开始

每个手册都是一个**单文件、零依赖**的交互式 HTML：

- 直接打开对应 `.html` 文件即可阅读（双击即用，无需联网）
- 支持亮/暗主题、目录导航、章节搜索、术语悬停解释、心法卡片手风琴、术语表搜索过滤、可勾选知识清单等交互
- 仓库中的 `.md` 文件是同内容的纯文本原稿，便于直接复制、二次编辑或打印

## 手册特色

- 🧭 **目录导航**：滚动自动高亮当前章节
- 🔖 **术语悬停**：正文蓝色术语，鼠标悬停/点击即查释义
- 🎴 **心法卡片**：可展开手风琴卡片，一次只展开一张

- 🌙 **亮暗主题**：适合不同环境阅读
- 📱 **响应式**：桌面 / 移动端均可流畅阅读
- 🖨️ **打印友好**：打印时自动展开全部卡片、隐藏侧栏
